## 🛠️ Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/estudopython.git
   ```

2. Entre na pasta:
   ```bash
   cd estudopython
   ```

3. Execute qualquer arquivo:
   ```bash
   python fundamentos/aula1_variaveis.py
   ```

> **Requisito:** Python 3.8 ou superior.
